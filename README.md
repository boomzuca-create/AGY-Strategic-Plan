# ระบบรายงานแผนยุทธศาสตร์สาธารณสุข จังหวัดขอนแก่น (AGY Strategic Plan)
### ระยะ 5 ปี (พ.ศ. 2566 – 2570) — สำนักงานสาธารณสุขจังหวัดขอนแก่น

เว็บแอปพลิเคชันระบบบริหารจัดการ ติดตาม และประเมินผลตัวชี้วัดเชิงยุทธศาสตร์สาธารณสุขแบบมัลติมิติ พร้อมระบบวิเคราะห์อัจฉริยะ (AI Intelligence & Predictive Analytics) และระบบร่างข้อเสนอโครงการอัตโนมัติ (Gem AI Assistant)

---

## 🌟 ฟังก์ชันเด่นของระบบ (Key Features)

1. **📊 แดชบอร์ดภาพรวมยุทธศาสตร์ (Strategic Overview & Executive Balance):**
   * กราฟใยแมงมุม (Radar Scorecard) วิเคราะห์ความสมดุล 5 ประเด็นยุทธศาสตร์หลัก
   * แผงติดตามความก้าวหน้ารายมิติ (5 Excellence Pillars) พร้อมเปอร์เซ็นต์ความสำเร็จและหลอดพลังแบบคู่
   * การ์ดสถิติสรุปภาพรวม (ตัวชี้วัดทั้งหมด, ร้อยละความสำเร็จ, ผ่านเกณฑ์, ไม่ผ่านเกณฑ์) สามารถคลิกเพื่อเจาะลึกได้ทันที

2. **🎯 ประเด็นยุทธศาสตร์ (Strategic Pillars Deep-Dive):**
   * รองรับโครงสร้างยุทธศาสตร์แบบไดนามิก ทั้ง 4 ด้าน (ปี 2566–2567) และ 5 ด้าน (ปี 2568–2570)
   * แสดงเกจวัดความสำเร็จ (Gauge Ring) คำอธิบาย และจำนวนตัวชี้วัดแยกรายยุทธศาสตร์

3. **📋 ระบบฐานข้อมูลและตารางตัวชี้วัด (KPI Master List & Freeze Header):**
   * ตารางแสดงรายการตัวชี้วัด 38–39 รายการต่อปี พร้อมระบบตรึงหัวตาราง (Sticky Header) เลื่อนดูข้อมูลได้สะดวก
   * ค้นหาและกรองตามยุทธศาสตร์ สถานะการประเมินผล ได้อย่างรวดเร็ว
   * แสดงค่าย่อยจำแนกระดับ/ประเภท (Sub-Values) เช่น ราย รพ., รพ.สต., หรือกลุ่มวัย

4. **📈 รายละเอียดตัวชี้วัดและกราฟแนวโน้ม 5 ปี (KPI Detail Modal & Templates):**
   * ตารางเปรียบเทียบผลงานจริง vs เป้าหมาย 5 ปี (2566–2570)
   * กราฟแนวโน้มเส้นประ-เส้นทึบแยกสถานะผ่าน/ไม่ผ่านอย่างชัดเจน
   * กล่อง Template ตัวชี้วัดฉบับเต็ม พร้อมสูตรคำนวณ ตัวแปร และหน่วยงานรับผิดชอบ
   * ระบบนำทางด่วน `KPI [ 1 ] / 38 [ GO 🚀 ]`

5. **✨ AI Strategic Intelligence & Prediction Center:**
   * ประเมินแนวโน้มและพยากรณ์ความเสี่ยงล่วงหน้าด้วยโมเดล AI
   * ข้อเสนอแนะเชิงนโยบายและการแก้ไขปัญหาตามหลักวิชาการ

6. **🚀 ระบบร่างโครงการด้วย Gem (AI Project Proposal Generator):**
   * ยกร่างเอกสารข้อเสนอโครงการสาธารณสุขฉบับสมบูรณ์ พร้อมดาวน์โหลดเป็นไฟล์ Word/PDF ได้ทันที

## 🚀 วิธีการติดตั้งและรันระบบบนคอมพิวเตอร์เครื่องใหม่ (Getting Started)

### ความต้องการของระบบ:
* [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)
* เว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari หรือ Firefox)

### ขั้นตอนการรัน:
1. **โคลนโปรเจกต์จาก GitHub:**
   ```bash
   git clone https://github.com/boomzuca-create/AGY-Strategic-Plan.git
   cd AGY-Strategic-Plan
   ```

2. **เริ่มการทำงานของ Server:**
   ```bash
   node server.js
   ```

3. **เปิดใช้งานบนเว็บเบราว์เซอร์:**
   * เข้าไปที่: [http://localhost:3000](http://localhost:3000)
